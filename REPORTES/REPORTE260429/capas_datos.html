Estructura de capas

Bronze

Capa de datos base con trazabilidad y definiciones de estructura minima.

  • Claves canonicas: identifica PK y FK para reconstruir el modelo relacional base.
  • Especificacion Bronze minima: define objetos, campos, tipos y trazabilidad para carga inicial.

Silver

Capa de refinamiento semantico, entidades, relaciones y politicas de historizacion.

  • Entidades canonicas: organiza entidades y atributos en lenguaje uniforme de negocio.
  • Claves: conecta entidades sin ambiguedad con llaves primarias y foraneas.
  • Particionado: define division fisica por fecha, periodo o entidad para mejorar rendimiento.
  • Historizacion: establece como conservar cambios en el tiempo por entidad o atributo.
  • Paquete Silver: consolida artefactos finales listos para entrega y publicacion tecnica.
Capa Que es Para que sirve Que conserva Que agrega
PBIX Modelo original de Power BI. Analizar y visualizar informacion. Tablas, columnas, medidas, relaciones y semantica del modelo. Visuales, DAX, filtros y comportamiento analitico.
Bronze Aterrizaje estructural y trazable del modelo. Llevar el PBIX a una base de datos utilizable. Tablas, columnas, tipos base, origen y trazabilidad. Convencion tecnica de carga y especificacion minima de objetos.
Silver Refinamiento del modelo para consumo. Preparar el uso analitico y el modelado posterior. La base estructural util heredada de Bronze. Entidades, claves, particionado, historizacion y paquete analitico.
Artefacto Capa Que organiza Para que sirve Resultado principal
Claves canonicas Bronze PK, FK y atributos marcados del modelo. Identificar como se conectan las tablas y cuales campos actuan como llaves. Base relacional inicial para reconstruir el modelo estructural.
Especificacion Bronze minima Bronze Objetos Bronze, campos, tipos y trazabilidad. Definir que tablas tecnicas se crean y que columnas se cargan desde el origen. Contrato minimo para aterrizar el modelo PBIX en base de datos.
Entidades canonicas Silver Entidades, atributos y relaciones canonicas. Traducir la estructura del PBIX a un lenguaje de negocio mas uniforme. Modelo logico refinado para consumo analitico.
Historizacion Silver Politica temporal por entidad y atributo. Definir que informacion debe conservar cambios en el tiempo y con que estrategia. Base para seguimiento historico y analitica evolutiva.
